# 철근 겹침이음 — 라벨링 규칙

**클래스 1개**: `lap_splice`
**박스**: 축정렬 바운딩박스

---

## 규칙

> **이음부처럼 보이면 박스를 친다.**
> 철근 두 가닥이 나란히 겹쳐 있는 부분을 감싼다.

끝이다. 애매하면 그냥 판단해서 넘어간다. 자기 판단을 믿고 속도를 유지한다.

경계가 몇 cm 어긋나는 건 상관없다. 평가를 `mAP50`으로 하기 때문에 IoU 0.5만 넘으면 정답이다.

**안 보이는 건 안 그린다** — 너무 작거나, 흐리거나, 대부분 가려져 있으면 넘어간다.

---

## 데이터 구성 — 여기만 지키면 된다

라벨 규칙은 느슨해도 되지만, 아래 셋은 어기면 **100장이 통째로 쓸모없어진다.**

### 1. 이음이 없는 사진을 20~30% 넣는다

박스 0개로 데이터셋에 **포함**한다(사진을 빼는 게 아니다).

안 넣으면 모델이 "철근이 보이면 이음"으로 학습한다. 이 도메인에서 가장 흔한 실패다.

### 2. 서로 다른 이음부를 30개소 이상 찍는다

**같은 이음부를 100번 찍으면 100장이 아니라 1장이다.**

같은 곳을 여러 각도로 찍는 건 좋다. 같은 자리에서 연사 30장은 1장으로 친다.

섞을 것: 거리(0.3m / 1m / 2m) · 각도 · 조명(맑음 / 그늘 / 역광) · 배근 밀도 · 녹·흙 상태

### 3. 학습/검증을 촬영 장소 단위로 나눈다

```
❌ 무작위 80:20
✅ 현장 A·B = 학습 (80장) / 현장 C = 검증 (20장)
```

같은 이음부를 찍은 사진이 학습·검증에 나뉘어 들어가면 **검증 점수가 가짜로 높게 나온다.**
사진 파일명이나 폴더로 어디서 찍었는지 구분해 둔다.

## 도구

**Roboflow** — 브라우저에서 바로 그리고 YOLO 포맷으로 내보내면 된다. 무료 플랜은
데이터셋이 공개되는데 이 프로젝트는 상관없다.

---

## 평가

**`mAP50`만 본다.** `mAP50-95`는 박스가 얼마나 딱 맞는지를 벌주는데, 경계가 원래
애매한 대상이라 볼 필요 없다.

그리고 검측에서는 **놓치는 것이 잘못 잡는 것보다 나쁘다.** 오검출은 사람이 화면에서
지우면 되지만 미검출은 검사를 안 한 것이다. 임계값을 낮게 잡아 **과검출 쪽으로 기울이고
사람이 거르는** 구조가 맞다.

---

## 100장으로 판단할 것

정확도를 재는 게 아니다. 100장으로는 못 잰다. 볼 것은 셋:

1. 학습 손실이 내려가는가
2. 검증셋에서 뭐라도 잡는가
3. 오검출이 어디서 나는가 — 패턴이 보이면 그때 규칙을 추가한다

`mAP50` **0.3~0.5**면 정상이다. **0에 가까우면** 그때 라벨 정의를 다시 본다.
